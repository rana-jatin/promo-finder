How it works

Five steps from script to shortlist

Each step is a stage in the pipeline. The labels under each card are the stage names you will see in the studio’s progress bar.

  1. 1

    Read the show

    Reads every timestamped line and writes a short show bible: who is who, what is secret, which tropes keep coming back.

    Parse · Bible
  2. 2

    Mine the moments

    Marks the hooks, reveals and cliffhangers in each episode, then links each set-up to its pay-off, even across episodes.

    Mine · Link arcs
  3. 3

    Cut candidate promos

    Stitches 20–60 s cuts in four shapes: one continuous scene, a cold open, an episode bridge, or two scenes from one story arc.

    Assemble
  4. 4

    Judge, repair, rank

    A judge that has not seen the script scores each cut as a viewer would. Weak cuts get a repair attempt, and the strongest ones can be compared head-to-head.

    Judge + repair · Select · Duels · Rank
  5. 5

    You make the call

    Approve, reject or nudge each promo. A rejected promo is replaced from the reserve and the list is re-ranked before anything is final.

    Editor · Write

Built-in rules

Every promo must pass four rules

These rules are checked in code, not by the model. A cut that breaks one is fixed or dropped before you ever see it.

20 s60 s
20–60 seconds

Long enough to tell a story, short enough to finish before the thumb moves on.

⚡0 s3 s
Hook within 3 seconds

The first line has to grab attention, so promos don’t open on scenery or set-up.

?
Ends on an open question

The cut stops before the answer, so the viewer has a reason to start the episode.

01:58.40⇄01:58.40
Timestamps round-trip

Every cut maps back to exact script timestamps, so an editor can find it in the footage.

What you get

A ranked shortlist you can actually use

  • Ranked promo cards, each with its timestamps, hook line, cliffhanger and the question it leaves the viewer with.
  • Scores you can read: hook, cliffhanger, works on its own, trope strength and pace, each out of 5.
  • A reserve list that refills the shortlist when you reject a promo.
  • Downloads: the final ranking as JSON, a readable report, your decisions, and every raw stage output.

Questions

Good to know

What files can I upload?

Plain .txt screenplays with timestamps on each line, one file per episode. The hosted demo takes up to 6 episodes. For a whole show, run it locally with python run.py --show <folder>.

How long does a run take?

The sample show replays in about a second. A live run on 3 episodes usually takes 3 to 15 minutes, depending on settings and how busy the model providers are. You can switch tabs while it runs.

Why does the page say it is waking up?

The demo runs on a free server that sleeps after 15 minutes without visitors. The first visit after that takes about a minute to start it again.

Can I change a promo the tool picked?

Yes. In the review step you can nudge where any segment starts or ends. The new cut snaps to the nearest valid line and is checked against the four rules again.

Is this an official Kuku FM product?

No. It is an independent prototype built for the Kuku FM AI Generalist assignment. The sample show is invented and contains no real show content.
